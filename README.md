# 花纸工艺实验台

本地运行的花纸分色演示，包含光谱四色、六色、Lab 专色和参考图七版套印模式。

## 运行

需要 Python 3。双击 `启动演示.cmd`，或运行 `python demo/serve.py --port 8765`，然后打开 http://127.0.0.1:8765/ 。无需安装第三方依赖。

## 七版套印

在“参考图七色 · 含盖白”模式中，每张版表示一次喷印覆盖位置。可分别导入 1–7 号客户单色版；导入版按灰度覆盖率使用，缺失版才由算法估计。屏幕颜色尚未经过实物颜料与烧成校准。

公开仓库仅包含经用户确认可公开的[合成总图](花纸.png)，不包含七张客户单色版和演示导出文件。如需在本地显示“载入客户七版样例”，可将获准使用的图片放在 `demo/data/customer-seven/`，命名为 `composite.png`、`plate-1.png` 至 `plate-7.png`。缺少单色版时，仍可上传总图并逐张导入版图。

使用方法、算法假设与验证边界见 [使用说明.md](使用说明.md) 和 [算法说明.md](算法说明.md)。运行 `node demo/verify-advanced.cjs` 与 `node demo/verify.cjs` 检查核心算法。
